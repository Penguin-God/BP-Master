전제조건 : 여기 나온 숫자들은 전부 바뀔 수 있으므로 하드코딩하면 안됨

밴과 픽을 지정된 순서만큼 번갈아가며 진행
총 5개의 카드를 뽑아 팀 스코어가 높은 쪽이 승리
팀 스코어 : 공격, 방어 기본점수 합 + 공, 방, 속 보너스 점수
각 카드를 뽑을 때마다 스킬을 사용할 수 있음
3판 2선제의 경우 양팀이 선택한 카드는 다음 게임부터 사용 불가능한 하드 피어리스 룰 적용

게임당 30장의 카드를 선택해 가지고 참가해야함
밴과 픽, 피어리스로 인한 선택 불가는 양 팀이 공유함
3판 2선의 경우 1판마다 카드를 10장씩 교체할 수 있음. 단, 그보다 낮은 수의 카드만 교체하는 것도 가능
교체가 끝났을 때 픽할 수 있는 카드의 수가 최소 20장이어야 함

-덱 구성 기능
덱이 요구치를 충족했는지 확인하는 기능
덱에서 선택한 요소를 빼기 -> 사용 가능한 카드에 추가됨
사용 가능한 카드를 내 덱에 추가하기 -> 사용 가능한 카드에서 사라짐
